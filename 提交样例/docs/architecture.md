# openJiuwen科研Agent架构设计文档

## 1. 整体架构

采用**主从多智能体架构**，基于openJiuwen原生调度框架，分为四层：

1. **接入层**：用户输入选题、约束条件
2. **调度层**：openJiuwen Agent调度器，分发任务给子Agent
3. **能力层**：规划Agent、撰写Agent、格式校验Agent、工具调用模块
4. **输出层**：Markdown论文、PDF导出、日志记录

## 2. 模块拆解

- 记忆模块：全局共享文献、草稿、校验结果
- 工具模块：文献检索、格式校验、PDF生成
- 校验模块：学术格式、关键词、摘要规范、参考文献格式校验

## 3. 数据流

用户选题 → 规划Agent输出大纲 → 撰写Agent生成正文 → 格式Agent校验 → PDF导出
